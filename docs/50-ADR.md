# ADR — 기술 선택 기록 (전 항목: 대안 ≥2 · 트레이드오프 · 출처 · 확인일)

> 사이클 5 산출물. 규칙: "벌거벗은 선택"(대안 비교 없는 채택) 금지. 확인일 명기 없는 주장 금지.

## ADR-01 데이터 인제스트 전략 — 파일데이터 우선, API는 증분용 ⚠️설계 변경
- **문제**: 초기 적재 = 2,000단지 × 36개월 ≈ 최대 7.2만 콜. 공공데이터포털 개발계정은 일평균 1,000건(확인 2026-09-16, 포털 안내). 운영계정 증량은 활용사례 등록+심의 필요 → D-4 내 불확실.
- **대안 비교**: (a) API 순차 콜 — 72일 소요, 탈락 (b) 운영계정 신청 — 심의 기간 리스크 (c) **K-apt 파일데이터(CSV 벌크) 다운로드 → 로컬 배치 적재** — 콜 수 0, 즉시 가능
- **결정**: **(c) 우선.** D1 게이트를 "API 필드 확인"에서 **"파일데이터 존재·스키마 확인 → 벌크 적재"**로 재정의. API(개발계정 1,000/일)는 월 1회 증분 갱신+온디맨드 단지 보충용으로만.
- **트레이드오프**: 파일데이터 최신성(공시 1~2개월 지연)은 어차피 API도 동일. 수동 다운로드 1회 수고 수용.

## ADR-02 인제스트 실행 환경 — 로컬 배치 스크립트 (Vercel cron 아님) ⚠️설계 변경
- **근거**: Vercel Hobby cron = **1일 1회 제한**, 함수 실행 상한 60~300s(확인 2026-09-16, vercel.com/docs/limits·plans/hobby — 문서 간 수치 상이, 보수적으로 60s 가정). 대량 적재에 부적합.
- **대안**: (a) Vercel cron — 제한 초과 (b) GitHub Actions cron — 가능하나 시크릿 배포 추가 (c) **맥 로컬 스크립트(초기 1회) + cron-job.org 무료(월 갱신 트리거, 분 단위 무제한)**
- **결정**: (c). uptime 핑도 cron-job.org로 통합(5분 간격 — Vercel cron으론 불가능했던 것. 기존 설계의 숨은 오류 정정).

## ADR-03 프레임워크 — Next.js (App Router)
- **대안**: SvelteKit(번들 작음, ISR 유사), Astro(정적 최강, 동적 API 약함), Remix
- **결정 사유**: ISR+OG 이미지+Vercel 통합이 1급 지원, 본인 숙련 스택(D-4 리스크 최소). Astro는 처방전 스트리밍(동적)과 부조화.
- **트레이드오프**: 번들 크기 열세 수용. 확인 2026-09-16.

## ADR-04 DB — Supabase Postgres
- **대안**: Neon(브랜칭, 콜드스타트 있음), Turso/SQLite(엣지, pg_trgm 없음), Vercel Postgres(=Neon 재판매)
- **결정 사유**: 무료 500MB(시계열 6테이블 충분), **pg_trgm 한글 단지명 유사검색**(ADR-07 의존), REST 즉시. 유휴 7일 중지 리스크 → cron-job.org 핑으로 상쇄(ADR-02).

## ADR-05 LLM — Claude (모델 ID·단가는 claude-api 스킬로 검증, 캐시 2026-06-24)
- **역할 분리**: 3중 일치 게이트 = `claude-haiku-4-5`($1/$5 per MTok) · 요약/해설/대필 = `claude-sonnet-5`($2/$10)
- **대안**: GPT/Gemini — 구조화 출력·한국어 품질 동급 이상 근거 없고, 본인 운영 숙련도·기존 코드 자산이 Claude. Upstage(TOP20 시 $30 크레딧)는 본선 이후 보조 후보로만.
- **트레이드오프**: 단일 벤더 종속 수용(데모 규모에서 무의미). 게이트 콜 단가 재계산: 기사 10건 판정 ≈ 3K tok in/0.3K out ≈ **$0.0045/단지** — 설계서의 "~₩30" 추정을 ₩6 수준으로 정정.

## ADR-06 뉴스 소스 — 네이버 검색 API
- **대안**: Google News RSS(비공식·차단 리스크), Bing News(유료화), 다음(공식 API 없음)
- **결정 사유**: 공식·무료 25,000콜/일·즉시 발급(확인 2026-09-16, developers.naver.com). 커버리지 한국 언론 최대.
- **트레이드오프**: 네이버 미제휴 언론 누락 가능 → 병력 문구에 "네이버 뉴스 기준" 명시.

## ADR-07 단지 자동완성 — Supabase pg_trgm 서버 검색
- **대안**: (a) 클라이언트 전체 목록 fuzzy(Fuse.js) — 4.5만 단지 ≈ 수 MB 초기 로드, 탈락 (b) Algolia — 과잉+비용
- **결정**: `ilike + pg_trgm` 인덱스, 디바운스 200ms. ponytail: 외부 검색엔진 금지.

## ADR-08 차트(Q4-a·d) — 인라인 SVG 직접 렌더
- **대안**: recharts(React 표준, "AI 생성물 기본 룩"), Chart.js(canvas, 디자인 통제 약함), d3(과잉)
- **결정 사유**: 궤적 스파크라인+분포 곡선 2종뿐 — 의존성 0, 도색 단계 디자인 통제 최대, AI 티 제거 목표와 정합. dataviz 스킬 원칙(마크 스펙 직접 제어) 적용.
- **트레이드오프**: 툴팁·축 직접 구현 비용 수용(2종 한정이라 소액).

## ADR-09 애니메이션(Q4-b·c) — CSS + IntersectionObserver + SSE 타이핑
- **대안**: framer-motion(번들 +50KB, 선언 편의), GSAP(라이선스·과잉)
- **결정**: 카운트업·신호등 점등 = CSS/JS 소량. 처방전 타이핑 = SSE 스트림 그 자체가 애니메이션(연출이 아니라 실제 생성 — 심사 정직성). `prefers-reduced-motion` 존중.

## ADR-10 유사 단지 산정 — 규칙 필터 (재확인)
- 40-DESIGN 기존 결정 유지. 추가 근거: 산식 공개 페이지에 "같은 시도·연식±5·세대수 구간·난방 일치"를 한 문장으로 쓸 수 있음 = 설명가능성이 법적 방어(J5). k-means는 이 문장이 불가능.

## ADR-11 OG 이미지 — @vercel/og (satori)
- **대안**: puppeteer 렌더(무겁고 Hobby 제한), 사전 정적 생성(단지별 동적 수치 불가)
- **결정**: Edge에서 JSX→PNG, 단지별 동적. 확인 2026-09-16.
