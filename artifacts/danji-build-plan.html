정부는 데이터를 열었다. 우리는 국민이 읽게 만든다.

정부 감사 표본의 72%에서 관리비 비리 1,255건이 나왔다. 국토부는 2026년 5월 전 단지 회계감사를 의무화했다. 그런데 그 데이터를 읽을 수 있는 국민이 없다. 단지 건강검진은 단지명 검색 30초로 관리비 3년 궤적, 장기수선충당금 건강도, 수선 이력 공백을 진단하고 — AI가 관리사무소 질의서까지 대신 쓴다.

"관리비가 싼 단지가 좋은 단지가 아닙니다.
미래를 안 쌓고 있는 단지일 수 있습니다."

01

왜 이 아이디어인가

60여 건을 생성하고 다 죽여본 뒤에 남은 결론. 스냅샷 비교는 전부 기존 제품이 있었고, 살아남는 건 "아무도 측정하지 않던 것"뿐이었다.

72%감사 표본 단지의 비리 적발률
1,255건비위·부적정 사례 (429단지)
'26.05국토부, 전 단지 회계감사 의무화
0개이 데이터를 읽게 해주는 소비자 제품
차별화 — 왜 기존 앱이 못 하나
아파트아이1,200만 세대
고객이 관리사무소·입대의 — 자기 고객을 비판하는 리포트를 낼 수 없다
직방 · 호갱노노
상품이 매물 — 자기 상품의 리스크를 보여줄 수 없다
K-apt (정부)
데이터는 있으나 해석이 없다. 검색 결과 전부가 "조회하는 법" 블로그
우리
이해관계 없는 유일한 "국민 쪽 감사관" — 구조가 해자다
한 문장 방어
"아파트아이는 이번 달 내 고지서의 위치를 말합니다. 우리는 이 단지의 10년 뒤 청구서를 말합니다."

비교(스냅샷)가 아니라 미래 리스크 진단(종단). 장충금을 안 쌓는 단지는 노후 공사가 닥치면 세대당 수백만 원이 일시 부과된다 — 이미 안양 등에서 터지고 있는 실제 사건이고, 어떤 앱도 이걸 미리 알려주지 않는다.

02

제품 — 검진표의 구조

건강검진의 언어를 그대로 쓴다. 검사 · 가족력 · 병력 · 처방전 · 정기검진.

층내용차별화 레버
검사 ① 관리비 궤적3년 시계열 — "난방비가 유사 단지보다 2배 빠르게 상승 중"종단성
검사 ② 장충금 건강도적립 수준 vs 경과연수·유사 단지 → 일시 부과 리스크 신호반사실 — 아직 안 온 청구서
검사 ③ 수선 공백유지관리 이력 등록 데이터로 "미뤄진 수선" 표시사실 화법
가족력같은 시도 + 연식 ±5년 + 세대수 구간 + 난방방식 일치 단지 분포 위 내 위치규칙 필터 — 설명가능성이 법적 방어
병력AI가 조사한 언론 보도(횡령·소송·감사 지적) — 3중 일치 게이트 통과분만, 기본 접힘무소음 원칙
처방전AI가 관리사무소 질의서·입주자대표회의 안건 초안 작성행동 대행
정기검진매달 새 데이터 반영 알림 + 전국 단지 공개 검진표(SEO)재방문 + 투표 유입
표현의 헌법. "등급 B-"라고 말하지 않는다 — 그건 의견이다. 신호등(양호/관찰/주의) + "유사 단지 하위 34%"라는 산술만 말하고, 산식 전문을 공개 페이지로 연다. 병력은 요약 2문장 + 원문 링크(인용 범위) + 정정 채널 24시간. 사실적시·인용·정정의 3중 방어.

5일 실행 일정

모든 항목에 시간 상자와 폴백. 컷 순서는 뒤에서부터: 랭킹 → 병력 → 처방전. 검진 3종 + 신호등이 최소 성립선이다.

D1 09.15
생사 게이트: 공공데이터 API 실호출 — 장충금·시계열 필드 실측 (3h) · 저장소+Vercel 첫 배포 (1h)
실패 → K-apt CSV 폴백
D2 09.16
인제스트 파이프라인 + 수도권 2,000단지 (4h) · 유사단지 통계 배치 (2h) · 검진표 화면 v0 (3h)
지연 → 500단지로 축소
D3 09.17
신호등·백분위 산식 + 산식 공개 페이지 (3h) · 병력 파이프라인 + 표본 50단지 오귀속 수동 검증 (4h)
오귀속 >2% → 병력 전체 드롭
D4 09.18
참가 접수 (오전 필수) · 처방전 생성 (3h) · 프리셋 + 공유카드 (3h)
처방전 지연 → 정적 템플릿
D5 09.19
랭킹 (2h) · 반응형·OG·엣지 상태 (3h) · 외부인 3명 테스트 (2h)
