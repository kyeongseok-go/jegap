# JEGAP 제값 — 내가 내는 값이 정당한가

**https://jegap-one.vercel.app** · 원티드 AI Championship 2026 출품작

정부가 이미 공개한 가격 공시를, 누구나 30초 안에 읽을 수 있는 **검진표**로 바꿉니다.
관리비 · 병원 비급여 · 학원비 · 장례비 · 생활물가 — **물어볼 권리가 법에 있는 가격만** 다룹니다.

| 편 | 데이터 | 규모 |
|---|---|---|
| 관리비 | 국토교통부 K-apt | 전국 21,165단지 · 월별 3년+ |
| 병원비 | 심평원 비급여 공개 | 병원급 3,944기관 · 18.6만 가격 |
| 학원비 | 교육청 NEIS 공시 | 21,038학원 · 표준 63과목 |
| 장례비 | e하늘 장사정보(공공누리 1유형) | 1,060개소 · 8.1만 항목가 |
| 생활물가 | 행정안전부 지방물가 | 35품목 × 17시도 × 6년 + 착한가격업소 12,645곳 |

## 원칙 (제품 헌법)

1. 무로그인 — 클릭 1회 안에 첫 가치
2. **판정하지 않는다** — 위치(백분위)·배수·사실 서술만. 산식은 [/method](https://jegap-one.vercel.app/method)에 전문 공개
3. **무소음** — 표본 부족·시계열 단절·공시 오류 의심 값은 표시하지 않는다
4. **AI는 문장만 쓴다** — 수치·신호는 전부 결정론 계산. Claude는 질의서·요청문의 문장을 다듬을 뿐
5. 가용성 > 기능 — 외부 DB 없음, 데이터는 앱에 내장

## 구조

```
app/
  app/            # Next.js 라우트 — / /d /h /a /f /p /method /design
  components/     # 검진표·검색·대필 공용 컴포넌트
  lib/engine/     # 관리비 검진 엔진 (백분위·완화 사다리·신호·소견)
  lib/pricedom/   # 가격 도메인 공용 엔진 (makeDomain 설정 선언)
  lib/{medical,academy,funeral,living}/  # 도메인 어댑터
  scripts/        # 인제스트 파이프라인 (원천별 python)
  data/           # 전처리 산출 번들 (.json.gz — 커밋이 곧 갱신 이력)
```

## 데이터 출처와 라이선스

- 국토교통부 K-apt 공동주택관리정보시스템 (공공데이터포털 개방)
- 건강보험심사평가원 비급여 진료비용 공개 — **비영리 사용, 환자 유인·알선 없음**
- 교육청 나이스(NEIS) 교육정보 개방 포털
- 한국장례문화진흥원 e하늘 장사정보 — 공공누리 제1유형(출처표시), 2023-06 공시분(화면에 기준 시점 명시)
- 행정안전부 지방물가 공개서비스 · 착한가격업소 현황

모든 화면은 조사 기준 시점을 명시하며, 정정 요청은 24시간 안에 처리합니다.
