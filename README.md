## 원칙 (제품 헌법)

1. 무로그인 — 클릭 1회 안에 첫 가치
2. **판정하지 않는다** — 위치(백분위)·배수·사실 서술만. 산식은 [/method](https://jegap-one.vercel.app/method)에 전문 공개
3. **무소음** — 표본 부족·시계열 단절·공시 오류 의심 값은 표시하지 않는다
4. **조건이 다르면 비교하지 않는다** — 단위·규격·기간이 어긋나는 값은 순위를 내지 않고
   "공시가격 참고"로만 보여준다 (아래 참조)
5. **AI는 문장만 쓴다** — 수치·신호는 전부 결정론 계산. Claude는 질의서·요청문의 문장을 다듬을 뿐
6. 가용성 > 기능 — 외부 DB 없음, 데이터는 앱에 내장

## 비교 단위 — 이 제품이 가장 공들인 곳

"중간값의 2.5배"는 **비교 대상이 같은 조건일 때만** 사실이다. 공시 데이터는 그렇지 않을 때가 많다.
실제로 잡아낸 오염 네 가지:

- **장례식장 안치료**가 416곳 한 표본(중간값 72,000원)이었는데, 그 안에 **1일 요금과 시간당 요금이
  섞여** 있었다. 단위로 나누니 1일 249곳(96,000원) / 시간당 113곳(5,000원)이다.
  → 기간 단위(일·시간·회)를 분리. 수량이 2 이상 명시된 항목은 순위를 내지 않는다.
- **학원 교습비 파서**가 과목명 속 쉼표에 걸려(`초등수학(주3회, 60분)`) `회60분)` 같은 코드를 만들었고,
  서울 송파구 124건이 그 코드 하나로 비교되고 있었다. 피아노와 바이올린도 "음악"으로 묶고 있었다.
  → 과목 표기 원문 + 교습계열로만 비교. 버려지던 학원 6,200곳이 복구됐다.
- **편의점 가격이 대형마트 표본에 섞였다.** 진라면 5개입이 대형마트·슈퍼 3,950원인데 편의점은
  5,000원이다. → 업태를 비교 키에 넣어 같은 업태끼리만 비교한다.
- **창업비용 "기타비용"**은 포함 범위가 브랜드마다 다르고(인테리어·장비·시설), 전체의 26%가
  항목을 일부만 공시해 그 "합계"가 전체 창업비용이 아니었다. → 기타비용은 순위 미산출,
  합계는 네 항목을 모두 공시한 브랜드끼리만 비교.

없는 값은 만들지 않는다. 교습 시간·횟수는 NEIS 공시에 항목 자체가 없고, 참가격 업태 코드의 뜻은
확인할 방법이 없었다. 추측하는 대신 **뜻을 몰라도 같은 코드끼리만 비교**하도록 구조로 풀었다.

## 데이터 출처와 라이선스

- 국토교통부 K-apt 공동주택관리정보시스템 (공공데이터포털 개방)
- 건강보험심사평가원 비급여 진료비용 공개 — **비영리 사용, 환자 유인·알선 없음**
- 교육청 나이스(NEIS) 교육정보 개방 포털
- 한국장례문화진흥원 e하늘 장사정보 — 공공누리 제1유형(출처표시), 2023-06 공시분(화면에 기준 시점 명시)
- 행정안전부 지방물가 공개서비스 · 착한가격업소 현황
- 공정거래위원회 가맹사업 정보공개 — 이용허락범위 제한 없음 · 무료 (연 1회 갱신)
- 한국소비자원 참가격 — 공공누리 제1유형(출처표시) · 무료 (격주 조사)
- 한국석유공사 오피넷 — 공공데이터포털 기준 제한 없음 (매일 조사).
  **오피넷 저작권정책은 수익 목적 이용 시 석유공사와 사전 협의를 요구합니다.**
  JEGAP은 비영리·무광고로 운영하며, 수익이 생기면 먼저 협의합니다.

출처별 이용 조건은 [/terms](https://jegap-one.vercel.app/terms)에 표로 공개합니다.
원문으로 확인하지 못한 출처는 "확인 중"으로 표기하며 추측하지 않습니다.
모든 화면은 조사 기준 시점을 명시하며, 정정 요청은 24시간 안에 처리합니다.

## AI 협업 기록

이 프로젝트는 AI 협업으로 개발되었습니다 — 전체 도구 목록과 역할은 [AI_TOOLS.md](AI_TOOLS.md),
개발 과정은 커밋 히스토리가 1차 기록입니다 (야간 자율 빌드 → 실데이터 전환 → 심사 루프 3라운드 →
Codex·적대 감사 교차검증 28건 반영).

6~8호 도메인은 `.loop/` 의 자동 진행 루프로 만들었습니다. 작업지시서(`LOOP.md`)·태스크 큐·
정지 조건을 문서로 고정하고, 매 커밋 전에 **회귀 관문**(`regress.py` — 살아 있는 화면의
보이는 텍스트를 기준선과 대조)과 **검증 스위트**(`verify.py` — 링크·a11y·헌법 감사·보안 헤더·
데이터 격리)를 통과해야 진행되도록 했습니다.

## 검증

```bash
cd app && npx tsc --noEmit && npx vitest run && npm run build
npx next start -p 4000 &
python3.14 .loop/verify.py      # 링크·a11y·헌법 감사·보안 헤더·데이터 격리
python3.14 .loop/regress.py --check   # 기존 화면 회귀
```

테스트 54개. 검증 기록은 [.loop/VERIFY.md](.loop/VERIFY.md),
교차검증 브리프와 결과는 [docs/2026-09-20-CROSS-EXAM-6to9.md](docs/2026-09-20-CROSS-EXAM-6to9.md).

상식 범위를 벗어나면 인제스트가 거부합니다). 참가격 업태 코드의 뜻은 확인하지 못해 화면에
