## 6. 루프가 못 한 것 — 솔직하게

- **프로덕션에서 확인하지 않았다.** 전부 로컬 기준이다.
- **실제 사용자 테스트를 하지 않았다.** 문구가 이해되는지는 사람이 봐야 안다.
- **참가격 업태 코드(LM/SM/DP/CS)의 뜻을 끝내 확인하지 못했다.** 뜻을 추측하지 않고
  같은 코드끼리만 비교하도록 구조로 해결했으나, 화면에 업태를 표시하지는 못한다.
- **크로스 브라우저·실기기 확인을 하지 않았다.** 헤드리스 Chrome 한 종류다.
- 생필품편은 대형마트 체인이 전국 동일가라 **배수가 대부분 1배**다. 사실이지만
  사용자가 느끼는 가치는 다른 도메인보다 낮을 수 있다.
- 오피넷 시군구 평균은 **개별 주유소가 아니다.** 탭 이름 "주유소"와 실제 해상도가
  어긋난다고 볼 여지가 있다(화면 문구에는 명시했다).
